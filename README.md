# 椰子小超人银行 · 部署与分享指南（给非 IT 家长的极简版）

> 目标：把这套积分银行变成一个**公网可访问的链接**，用微信发给全家，每个人用各自分配的账号登录，积分数据**所有人实时同步**。
> 你不需要懂代码。下面按"照着点"的步骤来。

---

## 一、先说清楚两件事（很重要）

### 1. 关于"微信登录"
系统用的是**内置账号登录**（不是微信一键登录）。原因：真正的微信扫码登录需要企业资质、备案域名、HTTPS 审核，对一个家庭项目不现实。
**实际效果一样**：你（管理员）把链接发到家庭微信群 → 家人点开 → 用你分配的账号（妈妈/爸爸/外公外婆/爷爷奶奶/宝宝）和密码（4 位 PIN）登录 → 各自身份和权限就确认了。谁加的分、谁申报的，系统都留痕。

### 2. 关于"数据会不会丢"（部署坑，必看）
当前数据存在服务器的一个文件里（不是数据库）。**免费平台在休眠/重启/重新部署时可能清空这个文件**。
系统已内置三层保护：
- ✅ **每日自动备份**：服务器每天自动存一份 `data/backup/state-日期.json`，保留最近 7 天。
- ✅ **手动导出备份**：管理员在「管理」页底部点「⬇️ 导出备份」，会把全部数据下载成一个 json 文件（建议每周一次，存到手机/电脑/微信收藏）。
- ✅ **手动恢复**：换服务器或数据丢失后，管理员点「⬆️ 导入备份」选中之前的文件，一键恢复全部积分和记录。
- ✅ 长期最稳方案：在家里一台**长期开机的电脑/树莓派/NAS** 上常驻运行（数据永远在自己手里），见第三节。

## 二、最简上线路径：Render.com（推荐）

Render 对 Node 程序最友好，自动给 HTTPS 链接，微信里能直接打开。

### 步骤（全程在电脑浏览器操作，约 10 分钟）

1. **注册 Render**：打开 https://render.com ，点 "Sign Up"，用 **GitHub 或 Google 账号**登录（免费层需绑定一张信用卡做身份验证，额度本身免费，不会扣费）。
2. **准备代码仓库**（本项目需要一个 GitHub 仓库）：
   - 打开 https://github.com 登录后，右上角 **+ → New repository**
   - Repository name 填：`coconut-bank`（随便起，英文即可）
   - 选 **Public**（免费层 Render 也能读私有库，但 Public 最省事），**不要勾选** "Add a README file"
   - 点绿色 **Create repository**
   - 进入空仓库页后，点中间大字 **uploading an existing file**（或 "Add file → Upload files"）
   - 把本压缩包解压出来的 **5 个文件**（`index.html`、`server.js`、`package.json`、`render.yaml`、`.gitignore`）**全部拖进去**
   - 拉到页面最下面，点绿色 **Commit changes**
3. **新建 Web Service**：Render 控制台点 "New" → "Web Service" → 连接刚建的 GitHub 仓库。
4. **配置**（照填）：
   - Runtime：Node
   - Build Command：（留空，或填 `npm install`）
   - Start Command：`node server.js`
   - Instance Type：**Free**（免费）
   - 环境变量：`PORT` 不用填，Render 会自动给。
5. **（可选）挂持久磁盘**：Render 免费层**不支持**挂磁盘，所以请务必每周用「导出备份」存一份数据（见第一节）。若后续升级到付费层，可在服务的 "Disks" 里新建 Disk，挂载路径填 `/workspace/data`，大小 1 GB。
6. **Deploy**：点 "Create Web Service"，等 1–2 分钟变成绿色 "Live"。
7. **拿到链接**：页面顶部有一个 `https://xxxx.onrender.com` 的地址，**复制它发到家庭微信群**即可。

> ⏰ 免费层的小毛病：15 分钟没人访问会"睡觉"，下次打开要等 30–60 秒才醒（第一次打开慢是正常的，不是坏了）。

> 家人打开后，用各自账号登录：妈妈/爸爸为管理员，可加分、审批、改规则；长辈可申报；宝宝可"我做到了"提醒大人。

## 三、备选：家里常开机设备自托管（数据最稳）

如果你家有一台**长期不关的电脑 / 树莓派 / NAS**，在这台机器上：

1. 安装 Node.js（https://nodejs.org ，装 LTS 版）。
2. 把本项目文件夹拷进去，在文件夹里打开终端，运行 `node server.js`。
3. 浏览器访问 `http://本机IP:8080` 就能用。
4. 想让**外网（微信）也能访问**：在这台机器上装一个内网穿透（如 Cloudflare Tunnel / 花生壳 / 樱花 frp），按它家教程拿到一个公网 https 链接，发给家人。

优点：数据 100% 在自己手里、永不清空。缺点：需要这台机器一直开机。

## 四、账号与权限（管理员怎么分配）

系统预设 5 个账号，管理员（妈妈/爸爸）把账号名 + PIN（4 位数字）告诉对应家人即可：

| 账号 | 角色 | 能做什么 |
|------|------|---------|
| 妈妈 / 爸爸 | 管理员 | 全维度加分、扣分、审批兑换、改规则、看全部数据 |
| 外公外婆 | 长辈 | 学习类小额直接加分（单笔≤3、日累计≤6）+ 全维度申报 |
| 爷爷奶奶 | 长辈 | 全维度申报（观察记录，不直接加分）|
| 宝宝 | 孩子 | 看积分、点"我做到了"提醒大人、申请兑换 |

> 初始 PIN：`妈妈 0000 / 爸爸 0000 / 外公·外婆 1111 / 爷爷·奶奶 2222 / 宝宝 3333`。
> ⚠️ **上线后第一件事**：管理员进「管理 → 账号权限 → 重置密码」把这些默认密码改掉（尤其宝宝账号，否则孩子自己能登录改分）。

### 改默认密码的另一种方式（改代码）
打开 `server.js`，找到第 126 行附近的 `DEFAULT_ACCOUNTS`，把 `pin:'0000'` 改成你要的 4 位数字即可。**注意**：只有服务器上还没有 `data/accounts.json` 时才会生效；已经生成的，请在网页里改。

## 五、本地自己先试（不联网也能跑）

不想部署也想先看效果：在装好 Node 的电脑上，项目文件夹里运行 `node server.js`，浏览器打开 `http://localhost:8080` 即可。这就是你之前预览的那个界面。
